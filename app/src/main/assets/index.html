Help

  1. Start the server in QuestSongBridge on the Quest.
  2. Read the URL and token from the app.
  3. Open this page on your Windows PC.
  4. Enter the token and save.
  5. Drag one or more song ZIPs onto the drop area.
  6. Wait for confirmation, then press Refresh in Beat Saber.

Troubleshooting: ensure PC and Quest are on the same Wi-Fi. Disable client isolation. If connection fails, check firewall.
